Use a numbered `NNNN-slug.md` page with `title` and `description` frontmatter. Follow the first record's sections of Status, Context, Decision, Consequences, and Evidence. Record the date and issue in Status, cite versioned evidence, and state when the choice should be revisited. A `type/decision` issue closes with the record.
